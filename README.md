# ПРОЗРЕНИЕ — запись голосовых команд

Открыть: https://matg0r.github.io/prozrenie-voice-recorder/

Бесплатная статическая страница GitHub Pages. Регистрация участникам не нужна.
Работает в современном Chrome/Safari через HTTPS при выключенном компьютере автора.

1. Укажите код участника без имени, подтвердите согласие (для ребёнка — родителя).
2. Разрешите микрофон, записывайте фразы после надписи «Говорите».
3. Прослушайте запись, при необходимости уточните произнесённый текст.
4. Нажмите «Сохранить и дальше», затем скачайте ZIP после сессии.

26 или 36 записей: десять команд с повторами и шесть отрицательных примеров.
Микрофон включается только для выбранной записи и выключается после неё.

## Где находятся записи

WAV и подписи сохраняются в IndexedDB браузера самого участника. Кнопка
скачивания создаёт ZIP на его устройстве. Аудио не загружается на GitHub
или какой-либо сервер. Автоматического обучения и исполнения команд нет.
На этом сайте нет аналитики или сторонних скриптов; GitHub обслуживает обычные
запросы страницы, как и у других сайтов на GitHub Pages.

После закрытия страницы сохранённую сессию можно продолжить в том же браузере.
Очистка данных сайта, приватный режим или нехватка места могут удалить записи:
скачивайте ZIP как резервную копию. Данные со старого адреса не переносятся
автоматически. Отправка ZIP организатору выполняется вручную самим участником.

В архиве заданная фраза отделена от подтверждённой фактической расшифровки.
При обучении разделяйте данные по коду участника, а не по отдельным файлам.
Согласие на передачу команде проекта не означает согласия на публикацию голоса.

Этот репозиторий содержит только интерфейс записи — без голосов, моделей,
ключей, настроек Jetson и исходников основного проекта.
